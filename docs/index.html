The official stamp for Agent ID holders

AgenTera is a free, soulbound on-chain badge on BNB Chain that only a verified Agent ID holder can claim. Ownership is checked directly against the official Agent ID contract — no server, no manual review, no trust required.

How it works

  • Agent ID is the key. The claim function calls balanceOf on the official Agent ID contract (0x60b9…022f). If your wallet holds an Agent ID, you can claim — otherwise the transaction reverts.
  • One badge, forever yours. The badge is a soulbound ERC-721: one per address, non-transferable, free. Gas only, paid by the claimer.
  • Stay active. Badge holders can check in once a day to build a public activity streak — a lightweight reputation layer for agent-operated wallets.
  • No owner, no admin, no fees. The contract cannot mint outside the claim function, cannot pause, and holds no user funds. Source code is public and verified on BscScan.
